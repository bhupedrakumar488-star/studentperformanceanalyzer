# Student Performance Analyzer

A Python-based project that analyzes a student's academic performance and displays the results in a simple and understandable way.

## Features

* Takes student details and subject marks as input
* Calculates total marks
* Calculates percentage and average
* Shows pass/fail result
* Finds the highest-scoring subject
* Finds the lowest-scoring subject
* Displays student performance using a graph

## Technologies Used

* Python
* Matplotlib

## Subjects

* DSTL
* COA
* TC
* MS
* DSA

## How It Works

1. Enter the student's name and roll number.
2. Enter marks for each subject.
3. The program calculates total marks, percentage and average.
4. It identifies the strongest and weakest subject.
5. The result is displayed along with a performance graph.

## Project Purpose

This project was created as a beginner-level Python project to understand programming concepts such as input handling, calculations, conditional statements, dictionaries, and data visualization.
